# 水的三态变化

水有三种状态：固态的冰、液态的水、气态的水蒸气。三种状态之间可以相互转化，温度变化是转化的主要条件。

水加热到 100 摄氏度时会沸腾，迅速变成水蒸气，这是汽化；水蒸气遇冷会重新变成液态水，这是液化。冬天窗户玻璃内侧常出现小水珠，正是因为室内空气中的水蒸气遇到冰冷的玻璃液化成小水珠，而玻璃外侧没有这样的小水珠。

冰温度升高到 0 摄氏度时开始熔化变成水；水温度降到 0 摄氏度时开始凝固成冰。汽化吸热，液化放热；熔化吸热，凝固放热。

# 观察与记录

做水沸腾实验时，应每隔一分钟记录一次温度，并观察气泡变化。沸腾前气泡上升过程中变小，沸腾时气泡上升过程中变大、到水面破裂，温度保持不变的这个温度就是水的沸点。
